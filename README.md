# RAI — Restaurant AI Telegram Mini App Demo

Демонстрационный prototype для презентаций и интервью с заведениями HoReCa.

## Что есть
- две роли: сотрудник и управляющий;
- обучение концепции;
- обучение меню;
- база знаний по виски;
- редактирование концепции, карточек, меню и базы знаний;
- чек-листы открытия/закрытия бара;
- локальный фотоотчёт;
- демонстрация QR check-in/check-out;
- карточка сотрудника;
- прогресс, часы и зарплата;
- аналитика команды.

## Важно
Backend отсутствует намеренно. Данные лежат в `src/data/mockData.js`, редактирования сохраняются в `localStorage`.

## Запуск
```bash
npm install
npm run dev
```

Открой адрес Vite, обычно `http://localhost:5173`.

## На iPhone в одной Wi-Fi сети
Vite покажет Network URL вида `http://192.168.1.15:5173`.
Открой его на iPhone. Windows Firewall может попросить разрешить Node.js доступ к локальной сети.

## Telegram
В `index.html` подключён Telegram WebApp JS. Для запуска внутри Telegram позже понадобится публичный HTTPS URL и бот.
